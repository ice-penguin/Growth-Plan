# 架构设计

```text
pc-admin (Vue2)            mobile-user (uni-app)
        │  HTTP / JSON            │
        └──────────┬──────────────┘
            Node Express (server/)
                    │
            MongoDB + mongoose
```

- PC：Vue 2.6 + Vue Router 3 + Vuex 3 + Ant Design Vue 1.x
- 用户端：uni-app，先出微信小程序
- 后端：Express + mongoose + JWT / passport-local
- 定时器：独立进程 `app_schedule.js`（端口 4545），主 API 不挂定时任务
- 模版：Excel / 消息等文件放 `server/templates/`，接口只返回 JSON，不再渲染服务端页面
- 部署：前后端分开构建；前端 `dist` 可由 Nginx 托管，接口反代到 Node
