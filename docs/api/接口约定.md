# 接口约定

- 前缀：`/api/<资源>`；登录在 `/auth`
- 每个资源一个目录：`index.js` 声明路由，`*.controller.js` 实现，`*.model.js` 定义模型
- 鉴权：
  - PC：`Authorization: Bearer <token>`，JWT 角色 `admin` / `organization` / `staff`
  - 小程序：`Authorization: Wechat <token>`，JWT 角色 `wechat`
- 统一 JSON：`{ code, data }`，业务错误常见为 HTTP 200 + `code: 409`

## 已实现

| 路径 | 说明 |
| --- | --- |
| `POST /auth/login` | PC 登录，body：`account`、`password` → Bearer token |
| `POST /auth/logout` | PC 登出 |
| `POST /auth/wx/login` | 小程序登录，body：`code`（uni.login）→ 按 openid 查/建用户 → Wechat token |
| `POST /auth/wx/logout` | 小程序登出（Header：`Wechat <token>`） |
| `POST /api/user/me` | 当前用户（PC / 小程序均可） |
| `POST /api/user/index` | 用户列表 |
| `POST /api/user/update` | 创建/编辑用户 |
| `POST /api/user/update/password` | 修改自己密码 |
| `POST /api/user/reset/password` | 重置密码 |
| `POST /api/user/delete` | 软删用户 |
| `POST /api/nav/get/login` | 登录后菜单 |
| `POST /api/nav/update/default` | 更新默认导航 |
| `POST /api/auth/index` | 权限列表 |
| `POST /api/auth/update` | 创建/更新权限 |
| `POST /api/role/index` | 角色列表 |
| `POST /api/role/update` | 创建/编辑角色 |
| `POST /api/role/update/auth` | 绑定权限 |
| `POST /api/upload` | 本地上传 |
| `POST /api/aliyun/upload` | 同上（兼容管理端配置） |
| `POST /api/config/show` | 配置占位 |

小程序需在 `tool/config/*.config.js` 的 `wechatMini.appId` / `appSecret` 填真实值。

定时器跑在独立进程 `app_schedule.js`；探活：`GET/POST /api/schedules/ping`（端口 4545）。
