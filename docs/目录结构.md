# 目录结构

单仓四块：`docs/` 设计文档、`server/` Node 后端、`pc-admin/` Vue2 管理端、`mobile-user/` 用户端小程序。

后端：每个业务一个文件夹，`index.js` 管路由，`*.controller.js` 管逻辑，`*.model.js` 管模型。  
PC：Vue CLI + Vue2 + Vuex，按业务拆 `views/` 和 `api/modules/`。  
用户端：uni-app + `common/` + `util/request/` + `pages/`，先出微信小程序。

先落地登录相关基础设施：用户、权限、角色、菜单、上传，业务模块确定后再加。

当前约定：

- 前后端、两个前端和文档放在同一个仓库。
- 定时器单独进程：`app_schedule.js` + `routes_schedule.js`，只跑 `api/z_schedule/timer`。
- 去掉服务端静态页 `views/`，导出 / 消息等模版放到 `templates/`。
- `server/package.json` 放在后端目录内，和两个前端分开装依赖。
